### Project Overview
Recreated BorrowBox Full-Stack Web Application demonstrating complete CRUD (Create, Read, Update, Delete) operations.

- **Frontend:** HTML5, JavaScript (Fetch API), Tailwind CSS
- **Database:** SQLite3

### Working Features
- [x] **Create:** Add new student record
- [x] **Read:** Display student list from Django REST API
- [x] **Update:** Edit existing student information
